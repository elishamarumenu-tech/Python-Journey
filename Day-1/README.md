# 🎲 Python Dice Roller

A simple **Dice Roller program in Python** that uses the `random` module to generate two random dice values between **1 and 6**.

## 📌 Description

This project is a beginner-friendly Python program that simulates rolling two dice.

The program:

* Asks the user whether they want to roll the dice.
* Generates two random numbers between 1 and 6.
* Displays the result of both dice.
* Continues until the user chooses to stop.
* Handles invalid choices.

## 🛠️ Technologies Used

* **Python**
* `random` module
* `while` loop
* `if-elif-else`
* `input()`
* `random.randint()`

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone the repository:

```bash
git clone https://github.com/elishamarumenu-tech/Python-Journey.git
```

3. Open the project folder:

```bash
cd Python-Journey
```

4. Run the program:

```bash
python day1.py
```
