# 🪙 Guess the Coin Challenge

A simple **Coin Guessing Game built with Python** where the player predicts whether the computer will choose **Heads** or **Tails**.

The computer randomly selects one of the two outcomes and checks whether the player's guess is correct.

## 📌 Description

The game works by:

1. Displaying a welcome message.
2. Asking the player to guess **Heads** or **Tails**.
3. Randomly selecting Heads or Tails.
4. Displaying the computer's result.
5. Comparing the player's guess with the computer's choice.
6. Displaying whether the player guessed correctly.

## 🛠️ Technologies Used

* **Python**
* `random` module
* `random.choice()`
* `input()`
* `if-else` statements
* f-strings

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the program using:

```bash
python coin_guess.py
```
